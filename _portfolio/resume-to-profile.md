At LinkedIn I worked on Resume to Profile, an LLM-based feature that extracts skills from a member's uploaded resume so they can build out their profile faster. I then expanded it to more parts of the site.

The work combined backend API development with experimentation: I evaluated LLM-powered features through A/B experiments and used SQL to analyze the results. It is where I learned how generative AI behaves at scale, and what it takes to make it trustworthy for real people.
